# Gomoku Poker

五目並べとポーカーを混ぜた、黒対赤のオンライン対戦ゲームです。

## ルール

- 黒と赤はそれぞれ、スートなしの A から K を2枚ずつ持ちます。
- 合計52枚、各プレイヤー26枚です。
- 手札は5枚まで補充されます。
- 盤に自分の数字カードを1枚置いたら相手の番になります。
- 自分のカードだけで連続5マスを作り、その5枚がポーカー役なら勝利宣言できます。
- 勝ちは自動判定ではなく、必ず「勝利宣言」ボタンで確定します。

## 役

ファイブカード、フォーカード、フルハウス、ストレート、スリーカード、ツーペア、ワンペアを判定します。

## ローカル起動

```bash
npm run dev
```

表示された `http://127.0.0.1:5173` をブラウザで開くとローカル対戦ができます。

## Firebaseでオンライン対戦

1. Firebaseでプロジェクトを作成します。
2. Firestore Database と Hosting を有効にします。
3. WebアプリのFirebase設定を `firebase-config.js` に入れます。
4. Firebase CLIでログインし、デプロイします。

```bash
firebase login
firebase init hosting firestore
firebase deploy
```

`firebase.json` と `firestore.rules` は同梱済みです。初期ルールは試作用に部屋の読み書きを開いています。公開運用では認証付きルールに変更してください。
